# Contributing

Thanks for taking the time to contribute.

## Getting set up

```bash
git clone https://github.com/gakshita/Agents.git
cd Agents
npm install
```

Use the Node version in `.nvmrc` (`nvm use`).

## Before you open a pull request

- Run `npm run typecheck` and make sure it passes.
- Keep commits focused; one logical change per commit.
- Update the README when you change behavior someone else depends on.

## Branch naming

Use `<type>/<short-description>`, for example `feat/agent-registry` or `fix/echo-context`.
